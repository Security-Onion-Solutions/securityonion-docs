Instant Insight
===============

.. note::

    This is an enterprise-level feature of Security Onion. Contact Security Onion Solutions, LLC via our website at https://securityonion.com/pro for more information about purchasing a :ref:`pro` license.

Starting in Security Onion 2.4.160, there is a new Instant Insight feature that will save you time as you triage alerts in our :ref:`alerts` interface. When you expand an alert and then click the ``GUIDED ANALYSIS`` tab, there will be several different questions that help guide your analysis. As you drill into each of these questions, you'll see that :ref:`soc` has already run the corresponding queries and automatically shows you the result of those queries.
